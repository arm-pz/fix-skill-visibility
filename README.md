# Fix Google Visibility Gaps for Agent Skills

Apply and verify the fixes from an audit of individual agent skill pages. Repair evidence-backed issues with canonical URLs, internal discovery, task-focused copy, or stale public listings and record the result for each finding.

## Install

```sh
npx skills add arm-pz/fix-skill-visibility
```

## Try it

> Use this visibility report to fix the missing catalog links and stale GitHub homepage. Show what changed and how you verified it.

Start with the findings from [Check Skill Visibility](https://github.com/arm-pz/check-skill-visibility) or an equivalent URL-level audit. The skill rechecks each issue, edits the source that owns it, and verifies the local build or public listing within the authorized scope. Search ranking is measured separately after changes go live.

See the [repair and verification guide](references/repairs.md). Part of [Skillsmith by Caffeinity](https://skillsmith.tech/).
